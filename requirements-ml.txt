#                 pip install -r requirements-ml.txt
#   (torch 2.13.0 wheels exist for cu126 and cu130; cu126 works with older drivers.
#    Check yours with `nvidia-smi`; see https://pytorch.org/get-started/locally/)
#
# Pins are the versions verified together in this repo's .venv (2026-10-25).
